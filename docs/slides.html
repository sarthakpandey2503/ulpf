ULPF

Universal Log Pre-processing Framework · SIH 26156 · NTRO

  • Any perimeter log in. One OCSF 1.3 event out. Original bytes kept.
  • New vendor = one YAML source pack, not a new parser codebase.
  • Air-gapped container. No cloud model and no external chain required.

What breaks today

Heterogeneous logs stall detection

  • Firewalls, proxies, and IDS boxes emit syslog, CEF, LEEF, JSON, CSV, and XML.
  • Teams spend the investigation writing source-specific parsers.
  • Normalization that drops fields silently breaks later detections.
  • Compliance needs the original event, not only the parsed copy.

Pipeline

Collect → sniff → pack → OCSF envelope → signed ledger

  • Collectors: syslog UDP/TCP/mTLS, HTTP, file. Kafka/Redpanda when you scale out.
  • Envelope: raw_data, unmapped.*, field_lineage, OCSF class.
  • Sinks: SQLite dashboard, Parquet, ClickHouse, Splunk HEC, Elastic, CEF.
  • Workers are stateless. Order per device is kept by partitioning on the sender.

What others will not show

Three checks, all offline

  • Parser generator. Drain3 plus an offline mapper. A local LLM may suggest fields. An admin must sign the pack.
  • Schema Fidelity. 551 datasets, 539 rules. Full envelope: 100% of raw verdicts preserved, 0 detections lost. Native OCSF paths alone: 174 lost.
  • Lineage. Merkle batch + Ed25519 hash chain. One edited byte fails /verify.
